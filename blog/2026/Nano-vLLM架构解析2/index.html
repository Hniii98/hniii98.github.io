1. 模型结构

Nano-vLLM支持的 Qwen3 0.6B 模型主体结构由图1所示，模型采用decode-only的结构。总体上，Nano-vLLM由核心的Attention、MLP、RMSNorm部件构成。当config中设置权重共享时，embedding和lm head共享权重。

Nano-vLLM在设计时，模型前向推理时候的分片逻辑包装在各个组件中，分片逻辑对于LMEngine是透明的。

2. 核心部件

2.1 embedding 与 lmhead

embedding 本质上是一个索引的规约操作。单机多卡环境下，不同的rank负责各自shard的权重矩阵。前向时，不同rank接收相同的输入，根据shard范围构建mask, 将shard范围外的的输入映射到shard内的起始位置。规约操作完成后，再利用相同的mask把无效的权重置0避免与真实的起始索引对应的权重混淆。最后，通过分布式原语all_reduce得到最终的embedding

lm head则实际上执行一个矩阵乘法。单机多卡环境下，以采用权重共享的情况为例，权重形状为

\[W_{\mathrm{embedding}} \in \mathbb{R}^{\mathrm{shard} \times \mathrm{hidden\_size}}.\]

Pytorch中linear对于权重的存储正好是转置的，因此共享权重是直接使用embedding中分片好的矩阵。

随后，计算得出的logits在输出维度上是分片的，因此通过分布式原语gather在主进程上得到最终的logits

在model的实现中，下层得到的输入由上层保证正确性，当前层只需考虑自身的分片策略带来的影响即可。例如上文提到的lm head, 它的输入由Attention中最后的o_proj保证不同rank之间传给lm head的输入是正确的，lm head只需要考虑embedding权重矩阵分片带来的影响。

2.2 Qwen3MLP

Qwen3由MergedColumnParallelLinear、RowParallelLinear、SiluAndMul3个部件构成。本质上是对输入做一个SwiGLU，表达式如下

\[\operatorname{SwiGLU}(X) = \Bigl[ \operatorname{SiLU}\bigl(XW_{\mathrm{gate}}^{\top}\bigr) \odot \bigl(XW_{\mathrm{up}}^{\top}\bigr) \Bigr] W_{\mathrm{down}}^{\top}.\]

Nano-vLLM通过MergedColumnParallelLinear将rank负责的gate和up映射权重矩阵shard拼接在一次，通过一次矩阵完成。

\[X\bigl(W_{\mathrm{gate\_up}}^{(r)}\bigr)^{\top} = \Bigl[ X\bigl(W_{\mathrm{gate}}^{(r)}\bigr)^{\top} \;\Bigm|\; X\bigl(W_{\mathrm{up}}^{(r)}\bigr)^{\top} \Bigr].\]

其中，当前 rank 的权重分片为

\[W^{(r)} = W\bigl[rI/P : (r+1)I/P,\;:\bigr] \in \mathbb{R}^{(I/P) \times H}.\]
  • $H$：输入特征维度，对应 hidden_size。
  • $I$：单个 gate 或 up 投影的完整输出维度，对应 intermediate_size。
  • $P$：张量并行 GPU 数，对应 tp_size。这里假设 $I$ 能被 $P$ 整除。
  • $r$：当前 rank，满足 $r \in {0, \ldots, P-1}$。

之后，在SiluAndMul模块中对输入进行chunk得到各自的分片，计算本卡的门控结果 $Z^{(r)}$。

最后，由于前者计算的结果是在output_size进行了分片，因此最后对于 $W_{\mathrm{down}}^{\top}$ 的矩阵乘法需要在对应方向上进行切片，来保证分块矩阵乘法的正确性。相关表达式统一写为

\[\begin{aligned} W_{\mathrm{down}}^{(r)} &= W_{\mathrm{down}}\bigl[:,\;rI/P : (r+1)I/P\bigr], \\[6pt] Z^{(r)} &= \operatorname{SiLU}\Bigl(X\bigl(W_{\mathrm{gate}}^{(r)}\bigr)^{\top}\Bigr) \odot \Bigl(X\bigl(W_{\mathrm{up}}^{(r)}\bigr)^{\top}\Bigr), \\[6pt] Y &= \sum_{r=0}^{P-1} Z^{(r)} \bigl(W_{\mathrm{down}}^{(r)}\bigr)^{\top} \\[6pt] &= \sum_{r=0}^{P-1} \Bigl[ \operatorname{SiLU}\Bigl(X\bigl(W_{\mathrm{gate}}^{(r)}\bigr)^{\top}\Bigr) \odot \Bigl(X\bigl(W_{\mathrm{up}}^{(r)}\bigr)^{\top}\Bigr) \Bigr] \bigl(W_{\mathrm{down}}^{(r)}\bigr)^{\top}. \end{aligned}\]

Qwen3Attention

Qwen3Attention 在实现 qkv 投影的时候，处理方式和上文的 gate_up 一样，只是这里需要针对kv head共享做权重矩阵的的切片处理。

因为causal mask，每个 token 的输出只依赖自己及之前位置的 K、V，后续 token 不会改变它已经算好的结果，所以 chunked prefill 成立。因此在attention计算的分支中，每次在送入flash attention 计算之前，先追加写入cache block本轮计算出的kv。
